# EasyNotes V1.0

A free program that is practical, easy to use, and allows you to format your notes in various ways.

When you first start the program from the extracted ZIP file,
a shortcut will be automatically created on your desktop.

## Features

* Search bar
* New Note / Delete Note
* Dark Mode / Light Mode
* Expandable window
* Working checkbox
* Bold, Italic, Headings
* Lists, Code lines
* Preview / Save / Export

### Tray Icon Options

* Show
* Hide
* New Note
* Quit

## How to Install

1. Download the ZIP file
2. Extract it
3. Open the folder and find `EasyNotes.exe`
4. Run `EasyNotes.exe`
5. A shortcut will be created on your desktop
6. Start taking notes! Format them as you like
